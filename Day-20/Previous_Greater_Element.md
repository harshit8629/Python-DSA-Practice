# Previous Greater Element
The previous greater element of an element x in an array is the first greater element to the left of x.

Given two distinct arrays nums1 and nums2, where nums1 is a subset of nums2, return the previous greater element for each element in nums1.

Example
Input:
nums1 = [3, 4, 2]
nums2 = [1, 3, 4, 2]

Output:
[-1, -1, 4]
