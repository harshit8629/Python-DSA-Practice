# Trapping Rain Water

Given n non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

This is one of the most famous hard array/list problems.

You need to calculate how much water can be stored between buildings.

This problem teaches:

Two pointers
Prefix maximum arrays
Optimization techniques
Space optimization
Complex array traversal

Target Complexity:

Time: O(n)
Example 1
Input:
height = [0,1,0,2,1,0,1,3,2,1,2,1]

Output:
6

Explanation:
6 units of water can be trapped.

Example 2
Input:
height = [4,2,0,3,2,5]

Output:
9
Example 3
Input:
height = [1,2,3,4]

Output:
0
