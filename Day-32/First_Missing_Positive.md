# First Missing Positive
Given an unsorted integer array nums, return the smallest missing positive integer.

You must implement:

O(n)

time complexity and use:

O(1)

extra space.

This is a very famous interview question.

The challenge is:

Ignore negatives
Place numbers in correct positions
Rearrange array efficiently

This problem teaches:

Cyclic sort
Index mapping
In-place hashing
Advanced array manipulation
Example 1
Input:
nums = [1,2,0]

Output:
3
Example 2
Input:
nums = [3,4,-1,1]

Output:
2
Example 3
Input:
nums = [7,8,9,11,12]

Output:
1
